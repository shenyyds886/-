# 悬浮窗数字显示脚本

基于 [Auto.js](https://github.com/hyb1996-guest/auto.js) / [AutoX.js](https://github.com/kkevsekk1/AutoX) 实现的悬浮窗小工具。通过识别屏幕上两组指示图标的颜色状态,计算冷却剩余时间,并用悬浮窗把倒计时数字实时显示在屏幕上。

## 功能

- 📊 实时识别屏幕像素颜色,计算左右两侧的冷却剩余时间
- 🎨 设置界面可自定义左右两侧文字**颜色**和**字号**,带实时预览
- 🔀 两种显示模式:
  - **单个显示**:屏幕上只显示一个数字,底部有"左/右"按钮切换
  - **同时显示**:左右两个数字一起显示
- 🖼️ 外框自动贴合数字显示区域,不用手动调坐标
- 📱 自动适配横竖屏切换
- 💾 设置自动保存,下次打开自动读取上次配置

## 使用方法

1. 手机安装 [AutoX.js](https://github.com/kkevsekk1/AutoX/releases)(或兼容的 Auto.js Pro / Hamibot 等)
2. 把 `1.js` 导入到脚本目录并运行
3. 首次运行会进入设置界面:
   - 选择左右两侧的颜色、字号
   - 选择显示模式
   - 点击"保存设置"
4. 点击"开始执行":
   - 会请求**截图权限**(用于识别屏幕像素颜色)
   - 会请求**悬浮窗权限**(用于显示数字)
   - 授权后即可在其他应用上方看到悬浮窗数字

## 权限说明

| 权限 | 用途 |
|---|---|
| 截图权限(MediaProjection) | 识别屏幕上指示图标的颜色状态 |
| 悬浮窗权限 | 显示数字悬浮窗 |

脚本不会读取、上传任何隐私数据,所有识别和计算都在本地完成。

## 参数调整

如果你的设备分辨率/UI布局和默认识别位置对不上,可以在 `main()` 函数里调整以下参数(带中文注释,照着改就行):

- `zuox` / `youx` / `zuoy` / `youy`:数字悬浮窗的初始位置
- `kuangbianju`:外框与数字之间的留白
- `window.zbjs()` 函数内:像素采样的起始坐标,需要根据实际UI位置校准

## 兼容性

在 AutoX.js 上开发测试。理论上兼容 Auto.js Pro、Hamibot 等使用相同 `ui`/`floaty` API 的运行环境,未逐一验证。
